👟 Nike Shoes Store

Nike Shoes Store is a React Native Expo application that showcases a Nike-inspired shoe store interface. It demonstrates product browsing, shoe details, cart management, and state handling using Redux, providing a clean and interactive mobile shopping experience.

✨ Key Features

* 👟 Browse available shoes
* 🖼️ View shoe product images
* 📦 Explore shoe details
* 🛒 Add products to cart
* 🗑️ Remove products from cart
* 🔢 Manage cart items
* 💰 Display product information
* 🔄 Redux-based state management
* 📱 Clean and responsive React Native UI
* 🎨 Nike-inspired shopping interface
* ⚡ Smooth shopping interactions
* 🛍️ Simple mobile shopping experience

🏗️ Architecture & Workflow

The application provides a product browsing interface where users can explore available shoes and view individual product details. Redux manages the shopping cart state, allowing users to add or remove products while keeping cart information synchronized across the application.

The project focuses on creating a simple e-commerce workflow with reusable React Native components, centralized state management, and a responsive mobile shopping interface.

🛠️ Tech Stack

React Native • Expo • JavaScript • Redux • State Management • Component-Based UI • Responsive Design

▶️ Run the App

1. Install dependencies

npm install

2. Start Expo

npx expo start

3. Run on Android

npx expo start --android

4. Run on iOS

npx expo start --ios

5. Run on Web

npx expo start --web

🎯 Project Purpose

This project demonstrates how to build a mobile shopping application using React Native, Expo, and Redux. It provides practical experience with product browsing, product details, cart management, centralized state management, reusable components, and creating an interactive e-commerce user interface.
